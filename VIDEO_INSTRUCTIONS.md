# Instructions pour ajouter la vidéo de défilé

## Étapes pour télécharger et ajouter une vidéo :

### Option 1 : Pexels (Recommandé - Gratuit)

1. Va sur **Pexels** : https://www.pexels.com/search/videos/fashion%20runway/

2. Choisis une vidéo de défilé que tu aimes, par exemple :
   - https://www.pexels.com/video/fashion-model-walking-in-the-runway-9512048/
   - https://www.pexels.com/video/a-woman-walking-down-the-runway-9512045/
   - https://www.pexels.com/video/models-doing-a-catwalk-9511841/

3. Clique sur **"Free Download"**

4. Choisis la qualité **HD 1920x1080** ou **Full HD 1920x1080**

5. Une fois téléchargée, **renomme** le fichier en `hero.mp4`

6. **Place-le** dans le dossier : `/public/videos/hero.mp4`

7. **Rafraîchis** ton navigateur sur http://localhost:3000

### Option 2 : Ta propre vidéo

Tu peux utiliser n'importe quelle vidéo de ton choix :

1. Assure-toi qu'elle soit au format **MP4**
2. Renomme-la en `hero.mp4`
3. Place-la dans `/public/videos/hero.mp4`

## Notes importantes :

- Le site fonctionne parfaitement même **sans vidéo** (fond noir élégant)
- Format recommandé : **MP4, 1920x1080, 25-30fps**
- Durée recommandée : **10-30 secondes** (elle bouclera automatiquement)
